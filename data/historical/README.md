# Historical Prompt Corpus

Do **not** place raw chat exports here.

Workflow:

1. identify a candidate prompt;
2. privacy-classify it as direct-use, sanitized-use or pattern-only;
3. remove context that can identify people/projects/accounts;
4. create a meaning-preserving clean reconstruction;
5. annotate noise categories;
6. manually review before committing.

A historical prompt is an N=1 longitudinal case-study observation, not evidence about all users or all people with dyslexia.
